# tools — third-party checks / 第三者ツールの照合

Independent tools, unaffected by MasterCopy, re-checking the same copy.

MasterCopy とは無関係な独立ツールで、同じコピーを照合した記録です。

| File | What it is | 説明 |
|---|---|---|
| `xxhsum_check.log` | xxhsum verification output | xxhsum の検証出力 |
| `rsync_check.log` | rsync --checksum comparison (no differences expected) | rsync --checksum 比較（差分なしのはず） |
| `ascmhl_verify.log` | ASC MHL (ascmhl) verification log | ASC MHL（ascmhl）の検証ログ |
